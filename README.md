# 📝 Student Registration Form

A simple and responsive **Student Registration Form** created using **HTML5**. This project collects basic student information such as personal details, academic information, and social profile links.

## 📌 Features

- Student Name
- Email Address
- Phone Number
- Roll Number
- Gender Selection
- Branch Information
- Academic Year
- Date of Birth
- GitHub Profile Link
- LinkedIn Profile Link
- Submit and Reset Buttons
- HTML5 Form Validation using `required` attributes

## 🛠️ Technologies Used

- HTML5

## 📂 Project Structure

```
Student-Registration-Form/
│── index.html
│── README.md
```

# 🏆 College Arm Wrestling Competition Website

A beginner-friendly, responsive event website developed using **HTML** and **Tailwind CSS** for promoting a College Arm Wrestling Competition. The website provides complete information about the event and allows participants to register through a separate registration page.

## 📌 Project Overview

This project is designed for a college sports event. It contains:

- Home page with event details
- Registration page
- Responsive design using Tailwind CSS
- Simple and clean user interface
- Beginner-friendly source code

---

## 🚀 Features

- 🎓 College branding and logo
- 🏋️ Arm Wrestling event banner
- 📅 Event date, time, venue, and entry fee
- 🏆 Prize information
- 💪 Weight categories
- 📋 Competition rules
- 📞 Contact section
- 📝 Separate registration page
- 📱 Mobile responsive layout
